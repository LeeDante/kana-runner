# 五十音之路 — 跑酷試玩版 V1.2

無需建置：直接開啟 `index.html`。若上架 GitHub Pages，使用 repo 根目錄部署。

## 操作

- 進入關卡後，每題依題型播放日文發音；聽音選字題會等朗讀結束再讓答案門從遠方出現。
- 按 `←` / `→` 或畫面左右按鈕決定跑道；放開按鈕即可，不用一直按住。門抵達角色面前才判定。
- 不按左右鍵，保持中央會在門抵達時自動放棄（算錯題）。
- 初始約 6 秒通過，連續答對逐步加速，最快約 4 秒；錯誤會減速。
- 按 `R` 可重播讀音。

## V1.2 跑道校正

修正角色落腳點與答案門的投影座標，左右選擇會平滑移動到各跑道中央（不再卡在分隔線上）。門速度保持原設定。

## 注意

音訊採裝置 `speechSynthesis`，不同裝置日語語音品質可能有差異。本版透視跑道由 Canvas 繪製，仍非精緻 3D 美術成品。
瀏覽器以 localStorage 保存歷史紀錄，請勿依賴它跨裝置同步。
